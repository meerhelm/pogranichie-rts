# Иконки интерфейса

Oct 16, 2026 · @Valentin Sobolev

## Общие правила

В нижней панели 84 иконки: 35 построек, 17 юнитов, 11 приказов, 15 технологий, 3 эпохи и 3 заклинания. Все иконки квадратные, 128×128 px; на кнопке панели они показываются примерно 58×58, в подсказке 64×64, в карточке выбранного 96×96.

| Группа | Откуда берётся | Файл в репозитории | Фон плашки |
| --- | --- | --- | --- |
| Постройки | спрайт готовой постройки (стадия done) из `art/sprites`, с тенью; командный цвет: ВКЛ красный, Орден белый | `ui/icons/buildings/<id>.png` | оливковый градиент |
| Юниты | портрет: та же модель, отрендеренная в Blender крупно (по пояс, всадник с головой коня, воз целиком), поворот три четверти | `ui/icons/units/<id>.png` | серый градиент |
| Приказы | нарисованный SVG | `ui/icons/orders/<name>.svg` | коричневый |
| Технологии | нарисованный SVG | `ui/icons/techs/<id>.svg` | тёмно-синий |
| Эпохи | нарисованный SVG | `ui/icons/ages/<id>.svg` | тёмно-красный |
| Заклинания | нарисованный SVG | `ui/icons/spells/<id>.svg` | фиолетовый |

Стиль SVG такой же, как у иконок ресурсов в верхней полосе: тёплые цвета (пергамент, бронза, сталь, дерево) с тёмным контуром, свет из левого верхнего угла. Иконки собираются скриптами: `python3 -m tools.art.icons` (постройки), `python3 -m tools.art.portraits` (юниты, нужен `bpy`), `python3 -m tools.art.ui_icons` (SVG). Игра находит иконку по id каталога (`IconDB`); если иконки нет, на кнопке остаётся только название. Когда появятся рисованные иконки художника, их кладут в те же файлы с тем же размером.

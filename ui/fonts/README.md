# Шрифты

- `PT_Sans-Web-Regular.ttf` — PT Sans, основной шрифт интерфейса (тема `ui/theme.tres`).
- `PT_Serif-Web-Bold.ttf` — PT Serif Bold, заголовки (вариант темы `Title`).

Оба от ParaType, лицензия SIL Open Font License 1.1 (`OFL.txt`), взяты из
[google/fonts](https://github.com/google/fonts/tree/main/ofl). Покрывают латиницу и кириллицу
всех пяти языков игры, включая і, ў, ї, є, ґ, ą, ę, ł, ż, ė, į, ų, ū (проверяет
`tests/unit/test_fonts.gd`).
